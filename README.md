# BSC EVM 新代币监听器

一个监听 BSC (Binance Smart Chain) 上指定地址新出现的 ERC20 代币的 Python 工具。

## 功能特点

- 🔍 监听指定地址中新出现的 ERC20 代币
- 🆕 检测首次出现的代币（之前没有的代币）
- 💰 当新代币数量超过阈值时发送告警
- 📱 通过 Webhook 实时推送通知
- 🔄 记录历史代币数据，支持断点续传
- 🌐 支持代理访问
- ⚡ 异步处理，高效稳定
- ⏰ 每 10 分钟检查一次

## 工作原理

1. **代币发现**: 通过 BSCScan API 获取地址的所有 ERC20 代币交易记录
2. **代币提取**: 从交易记录中提取唯一的代币合约地址列表
3. **变化检测**: 与上次记录的代币列表进行比较
4. **新代币识别**: 找出首次出现的代币（新代币）
5. **余额检查**: 获取新代币的当前余额
6. **阈值判断**: 如果新代币数量超过设定阈值，发送告警
7. **数据持久化**: 将代币列表保存到文件，下次启动时继续

## 安装依赖

```bash
pip install -r requirements.txt
```

## 配置

创建 `.env` 文件并配置以下参数：

```env
# BSC API 密钥 (从 https://bscscan.com/apis 获取)
BSC_API_KEY=your_bscscan_api_key_here

# Webhook URL (钉钉机器人或企业微信机器人)
WEBHOOK_URL=https://your-webhook-url-here

# 代理设置 (可选)
USE_PROXY=false
PROXY_URL=

# 监听的地址列表 (JSON 数组格式)
MONITOR_ADDRESSES=["0x1234567890abcdef", "0xabcdef1234567890", "0x9876543210fedcba"]

# 新代币数量阈值 (默认 1M = 1000000)
NEW_TOKEN_AMOUNT_THRESHOLD=1000000

# 检查间隔 (秒，默认 600 = 10分钟)
CHECK_INTERVAL=600
```

## 告警触发条件

- 检测到地址中出现**新的 ERC20 代币**（之前没有的代币）
- 新代币的**当前余额数量**超过设定阈值
- 默认阈值为 **1,000,000** 个代币

## 注意事项

1. **API 密钥**: 需要有效的 BSCScan API 密钥
2. **地址格式**: 地址必须是有效的以太坊地址格式
3. **数据持久化**: 代币记录会保存到 `token_records.json` 文件
4. **首次运行**: 第一次运行时会记录当前所有代币作为基准
5. **网络要求**: 确保能够访问 BSCScan API
6. **API 限制**: 建议设置合理的检查间隔以避免 API 限制

## 配置地址格式

支持两种地址配置格式：

### JSON 数组格式 (推荐)
```env
MONITOR_ADDRESSES=["0x1234567890abcdef", "0xabcdef1234567890", "0x9876543210fedcba"]
```

### 兼容字符串格式
```env
MONITOR_ADDRESSES=0x1234567890abcdef,0xabcdef1234567890,0x9876543210fedcba
```

## 故障排除

- **API 密钥错误**: 检查 `.env` 文件中的 `BSC_API_KEY`
- **Webhook 发送失败**: 检查网络连接和 `WEBHOOK_URL` 配置
- **代币信息获取失败**: 确认网络连接正常
- **地址格式错误**: 检查地址是否为有效的以太坊地址格式
- **配置项为空**: 检查 `.env` 文件中的配置项格式

## 高级配置

### 自定义阈值

```env
# 设置不同的阈值
NEW_TOKEN_AMOUNT_THRESHOLD=500000      # 50万个代币
NEW_TOKEN_AMOUNT_THRESHOLD=10000000    # 1000万个代币
```

### 多地址监听

```env
# 监听多个地址
MONITOR_ADDRESSES=["0xaddr1", "0xaddr2", "0xaddr3", "0xaddr4"]
```

### 调整检查频率

```env
# 每 5 分钟检查一次
CHECK_INTERVAL=300

# 每 30 分钟检查一次
CHECK_INTERVAL=1800
```

## 风险提示

- 新代币可能存在欺诈风险，请谨慎判断
- 建议结合其他风险评估工具进行综合分析
- 大量新代币可能表明地址参与了高风险活动
